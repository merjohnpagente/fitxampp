# fitxampp
# FITCORE GYM MANAGEMENT SYSTEM
# SOFTWARE ENGINEER PROJECT

XAMPP + PHP + MySQL version — single index.html SPA with MySQL backend.

## Quick Start (XAMPP)
1. Copy to C:/xampp/htdocs/fitcore/
2. Start Apache + MySQL
3. Import database.sql in phpMyAdmin (DB: fitcore_gym)
4. Visit http://localhost/fitcore/check.php then http://localhost/fitcore/

Default logins: admin/admin123, staff/staff123, trainer/trainer123, nicole/member123
See README_XAMPP.md for full guide.
